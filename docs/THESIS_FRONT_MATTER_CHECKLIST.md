# Thesis front matter checklist (Word / submission pack)

Apply faculty rules first; this list is a reminder aligned with common School of Computing project formats.

## Preliminary pages (roman numerals often ii, iii, …)

- [ ] Title page (no page number or as directed).
- [ ] Declaration of originality (signature, date).
- [ ] Approval page (supervisor signatures as directed).
- [ ] Dedication (optional).
- [ ] Acknowledgements.
- [ ] Abstract (about 180–210 words if using Lec 1 sketch: background, problem, proposed solution, method and outcome).
- [ ] Table of contents.
- [ ] List of figures (with page numbers).
- [ ] List of tables (with page numbers).
- [ ] List of abbreviations and acronyms (PHI, API, RAG, NER, RBAC, GDPR-style terms, etc.).

## Main body (arabic numerals from Chapter 1)

- [ ] Chapter 1 Introduction … through Chapter 6 Conclusion (and references).
- [ ] Page numbering restarts at 1 for Chapter 1 if required by guide.

## End matter

- [ ] References (APA 7th as required).
- [ ] Appendices (labelled Appendix A, B, C …).

## Typical appendix contents for this project

- [ ] **Appendix A:** Logical database specification (paste from [LOGICAL_SCHEMA.md](LOGICAL_SCHEMA.md) or export from Word) and/or **Gantt chart** (full project timeline).
- [ ] **Appendix B:** API summary (paste from [API_SPEC.md](API_SPEC.md) or generated OpenAPI excerpt).
- [ ] **Appendix C:** Dataset description, training parameters, evaluation tables (from [PHI_Model_Training_Guide.md](PHI_Model_Training_Guide.md), training logs, or notebook exports).
- [ ] **Plagiarism / Turnitin** percentage report if required (separate appendix or combined with A/B).

## Figure and table numbering

- [ ] Figures: **Figure X.Y** where X is chapter number (consistent with [figures/README.txt](figures/README.txt)).
- [ ] Tables: **Table X.Y** same rule.
- [ ] Captions: tables above, figures below (per [Formatting guidelines.txt](Lectures%20and%20guides/Formatting%20guidelines.txt)).

## Plain-text bundle for supervisor review

- [ ] [SUBMISSION_CHAPTERS_1_3.txt](SUBMISSION_CHAPTERS_1_3.txt) updated if Chapter 1–3 text changes (regenerate from the three chapter `.md` files; legacy copy also at [FINAL_SUBMISSION_Chapters_1_to_3.txt](FINAL_SUBMISSION_Chapters_1_to_3.txt)).
